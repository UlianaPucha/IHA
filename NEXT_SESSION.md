Продолжаем проект **IELTS Reading Trainer** в папке `.`. Это React-приложение для подготовки к IELTS Academic Reading и пополнения словаря.

**Сначала прочитай целиком:**
- `CLAUDE.md` — правила проекта;
- `AGENTS.md` — правила запуска, особенности проекта, ритуалы обновления документов;
- `PRD.md` — функции, сценарий, раздел «Текущее состояние», таблица «Планы», журнал «Ход работы»;
- `DESIGN.md` — дизайн-токены и правила (концепция 2);
- папку `plans/` — планы 01–06, все выполнены.

По правилу из `CLAUDE.md`: если правила противоречат друг другу или моему запросу, сначала спроси меня.

## Что работает
- **Сценарий целиком:**
  - список из 3 текстов → чтение;
  - ответы A–D плитками → «Проверить»;
  - разбор рядом с текстом;
  - слова в словарь через попап: подсвеченное слово с готовым переводом или любое со своим;
  - карточки «Знаю / Не знаю» → итог сессии с полоской.
- **Словарь:** статусы «учу» / «выучено», удаление, пустые состояния, «Все слова выучены → Повторить все слова».
- **Данные:** в `localStorage` (`ielts.vocab`, `ielts.results`), переживают перезагрузку. Повреждённые данные или недоступное хранилище не роняют приложение.
- **Нижняя панель:** главные кнопки чтения и карточек закреплены внизу окна. Длинные переводы переносятся, флеш-карточка растягивается по высоте.
- **Дизайн — концепция 2 «тёплый учебный дашборд»** по `DESIGN.md` на Mantine 9.7.4 (тема `src/theme.js`):
  - **фон и карточки:** тёплый белый фон, пастельные карточки текстов по темам одна под другой, бежевые плитки ответов, белые карточки;
  - **акценты:** выбранный ответ — с синей обводкой, основные кнопки и активный пункт меню чёрные, метка «Правильно X из Y» белая;
  - **шапка:** во всю ширину, с линией снизу;
  - **шрифты:** Manrope, абзацы IELTS — Inter;
  - **кнопки:** все ровно 44 px, Manrope 15 px / 600, отступы 20 px;
  - **доступность:** контраст текста не ниже 4.5:1, видимый фокус;
  - **узкий экран:** нет горизонтальной прокрутки на 375 px.
- **Проверки:**
  - все три из раздела 8 PRD пройдены на концепции 2;
  - `npm run build` проходит без ошибок;
  - `npm run preview` работает.

## Ограничения
- Только 3 встроенных текста (`src/data/passages.json`) и только вопросы multiple choice.
- Данные хранятся только в этом браузере. Ответы до проверки сбрасываются при перезагрузке.
- Шрифты Manrope и Inter загружаются из Google Fonts. Без сети вместо них системный гротеск.
- Сборка: JS ≈ 388 КБ, CSS ≈ 256 КБ.
- **Запуск и порты:**
  - dev-сервер — конфигурация `ielts-dev` в `.claude/launch.json` (127.0.0.1:5173, `--strictPort`), сборка — `ielts-preview` (127.0.0.1:4173);
  - встроенный браузер работает только с `127.0.0.1`;
  - если 5173 занят другой сессией, сервер не стартует;
  - у каждого порта своё хранилище, мои данные — на 5173.
- Известная проблема: попап с очень длинным переводом (≈260 символов) на телефоне перекрывает нижнюю панель примерно на 30 px.
- **Git:**
  - репозиторий создан, но **коммитов нет** — по моему решению;
  - удалённого репозитория нет;
  - `.claude/settings.local.json` с личными разрешениями — вопрос, коммитить ли его, не решён.
- Тестов нет по решению. React и Vite указаны через `^`.

## Не проверено
- Firefox, Safari и настоящий телефон с сенсорным экраном.
- Работа без интернета (запасной шрифт).
- Настоящий приватный режим. Отсутствие `localStorage` проверено только имитацией в Chromium.
- Настоящий экранный диктор.
- Большой словарь на медленном телефоне.
- **На концепции 2:**
  - ввод своего перевода в попапе;
  - очень длинный перевод;
  - словарь на 300 слов.

## Как работать
- Перед проверками в браузере сохраняй мои данные из `localStorage` (`ielts.vocab`, `ielts.results`) на том порту, где идёт проверка, и восстанавливай после. Мои слова и результаты не должны пропасть.
- Ход работы записывай в журнал `PRD.md` («Ход работы»). Новые планы сохраняй отдельными файлами в `plans/`, обновляй их статусы в таблице «Планы».
- Код не меняй без согласованного плана. Интерфейс меняй только после чтения `PRD.md` и `DESIGN.md` целиком.
- Если изменились запуск, порты, структура или ритуалы, обнови `AGENTS.md`.
