# AGENTS.md — IELTS Reading Trainer

Инструкции для любого ИИ-агента, который работает с проектом. Claude Code подгружает этот файл через `@AGENTS.md` в [CLAUDE.md](CLAUDE.md). Общение с пользователем и тексты интерфейса — на русском.

## 1. Что прочитать перед изменениями

- [CLAUDE.md](CLAUDE.md) — ключевые правила проекта.
- [PRD.md](PRD.md) — функции, экраны, тексты и сценарий; особенно «Текущее состояние» и таблица «Планы».
- [DESIGN.md](DESIGN.md) — дизайн-токены и раздел Do's and Don'ts.
- [ARCHITECTURE.md](ARCHITECTURE.md) — части приложения, сущности и поля, связи, хранение данных, ограничения. Читать перед изменением данных, хранилища или структуры `src/`.
- **Перед любым изменением интерфейса** (экраны, компоненты, стили, тексты) прочитать PRD.md и DESIGN.md целиком.
- Нужный план в [plans/](plans/). Код меняется только по согласованному плану.
- Новый план — отдельный файл `plans/NN-краткое-имя.md` (статус, основание, шаги, что не входит), старые не перезаписываются.
- Функции из раздела 9 PRD и любые новые функции — только после согласования.
- Если правила противоречат друг другу или запросу, спросить пользователя, а не выбирать самому.
- [NEXT_SESSION.md](NEXT_SESSION.md) может отставать: актуальное состояние смотреть в PRD.

## 2. Как запускать

| Что | Команда | Адрес |
|---|---|---|
| Установка | `npm install` | — |
| Разработка | `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort` | http://127.0.0.1:5173 |
| Сборка | `npm run build` | папка `dist/` |
| Проверка сборки | `npm run preview -- --host 127.0.0.1 --port 4173 --strictPort` | http://127.0.0.1:4173 |

- В Claude Code запускать через `.claude/launch.json` (`ielts-dev`, `ielts-preview`), а не командой в терминале.
- Только `127.0.0.1`, не `localhost`: встроенный браузер не открывает `localhost`.
- Если 5173 занят сервером другой сессии, не останавливать его. Запустить свой на другом порту и сказать пользователю, на каком.

## 3. Особенности проекта

- **Стек:** React 19, Vite 8, JavaScript, npm; Mantine 9.7.4 (`@mantine/core`, `@mantine/hooks`), версия закреплена точно. Новые элементы — на Mantine, другие библиотеки — только по согласованному плану.
- **Маршрутизатора нет.** Без входа [src/App.jsx](src/App.jsx) показывает экран `Auth`; после входа — компонент приложения с `key={userId}`, где экраны переключает состояние `screen`, и там же словарь, результаты, ответы, экран и сессия карточек.
- **Вход — mock** ([src/auth.js](src/auth.js)): не подтверждает личность и не защищает данные, внешних систем нет. Не подключать сервисы входа без согласованного плана.
- **Где что лежит:**

  | Путь | Что там |
  |---|---|
  | `src/screens/` | экраны `Auth`, `PassageList`, `Reading`, `Vocabulary`, `Flashcards` |
  | `src/components/` | `WordPopup` — попап слова, `BottomBar` — нижняя панель на чтении и карточках, `TransferModal` — окно переноса данных |
  | `src/auth.js` | mock-вход: регистрация, вход, выход, сессия, перенос старых данных |
  | `src/theme.js` | тема Mantine из токенов DESIGN.md |
  | `src/index.css` | CSS-переменные тех же токенов и раскладка экранов |
  | `src/storage.js` | `localStorage` в try/catch (без хранилища — в памяти) с проверкой формы данных |
  | `src/data/passages.json` | контент: 3 текста, вопросы multiple choice, подсвеченные слова |

- **Данные пользователя** — в `localStorage`, все ключи начинаются с `ielts.`: аккаунты `ielts.users`, вход `ielts.session`, данные аккаунта `ielts.u.<userId>.*` (словарь, результаты, ответы, экран, карточки), старые данные до входа `ielts.vocab` и `ielts.results`. Полный список — в PRD, раздел 6. **У каждого порта своё хранилище**, данные пользователя — на 127.0.0.1:5173. Не открывать приложение на 5173 для проверок: там может появиться окно переноса на данных пользователя.
- **Кнопки:** все 44 px, Manrope 15 px / 600, отступы 20 px; проп `size` не используется. Варианты: `primary`, `secondary`, `secondary-on-surface`, `nav`, `nav-active`.
- **Цвета, шрифты, отступы** не задавать числами в коде: брать из `src/theme.js` и переменных `src/index.css`, которые синхронны с DESIGN.md.
- **Шрифты:** Manrope — заголовки и интерфейс, Inter — только абзацы текста IELTS (Google Fonts в `index.html`).
- **Тень попапа** — `--word-popover-shadow` (имя `--popover-shadow` занято Mantine). Попап не должен уходить под `BottomBar`: у `Popover` стоят `middlewares` с `padding`.
- **Тестов нет** — не добавлять.
- **Git:** коммитить только после явного подтверждения пользователя, никуда не пушить. `dist/` — результат сборки, вручную не править.

## 4. Что проверить после доработки

1. `npm run build` проходит без ошибок.
2. Перед проверкой в браузере сохранить все ключи `ielts.` на том порту, где идёт проверка (в консоли страницы):
   `JSON.stringify(Object.fromEntries(Object.keys(localStorage).filter(k => k.startsWith('ielts.')).map(k => [k, localStorage.getItem(k)])))`
3. Во встроенном браузере пройти проверки из раздела 8 PRD на ширине 1100 px и 375 px. На 375 px нет горизонтальной прокрутки, в консоли нет ошибок.
4. Если менялся интерфейс — сверить с DESIGN.md: кнопки 44 px, цвета, шрифты, Do's and Don'ts.
5. Восстановить данные: удалить ключи `ielts.`, которых не было в копии, вернуть остальные и сверить с копией.

## 5. Какие документы обновить

- **Изменилось поведение, экраны или тексты** → PRD.md: разделы 3–4 и «Текущее состояние» («Работает», «Известные проблемы», «Не проверено», «Следующий шаг»).
- **Изменился внешний вид** → DESIGN.md (токены, текст разделов, при необходимости Do's and Don'ts) и синхронно `src/theme.js` и `src/index.css`.
- **Изменились сущности, поля, хранение, связи или структура `src/`** → ARCHITECTURE.md.
- **Выполнялся план** → его файл в `plans/` (статусы шагов, итог проверки, отступления с причиной) и таблица «Планы» в PRD.
- **После любой работы** → запись в журнал PRD «Ход работы» (`### ГГГГ-ММ-ДД — что сделано`): что изменилось, как проверено, что не проверено. Если код не менялся — указать в заголовке.
- **Изменились запуск, порты, структура или эти правила** → этот файл.
