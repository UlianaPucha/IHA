# Текст PRD.md

# PRD: IELTS Reading Trainer (v1)

## 1. Для кого и зачем
Для русскоязычного студента, который готовится к IELTS Academic Reading. Приложение решает две задачи одним потоком: тренировать чтение текстов в формате экзамена и сразу превращать незнакомые слова из прочитанного в личный словарь, который потом можно повторять.

## 2. Основной сценарий
Открыть текст → ответить на вопросы → увидеть результат → сохранить незнакомые слова → повторить их карточками.

Функции v1 (4):
1. **Чтение текста с вопросами multiple choice** (A–D) и проверкой ответов.
2. **Результат:** счёт, правильные и неправильные ответы с указанием верного варианта.
3. **Добавление слов в словарь:** клик по подсвеченному слову открывает готовый перевод и пример; клик по любому другому слову открывает форму, где перевод вводит пользователь.
4. **Повторение карточками «Знаю / Не знаю»** по словам из словаря.

## 3. Экраны и навигация
Сверху всегда видно меню: `IELTS Reading | Тексты | Словарь (N)`.

```
Тексты ──► Чтение ──► Результат ──► Тексты
              │                  └► Словарь
              └ (попап слова → в словарь)
Словарь ──► Карточки ──► Словарь
```

| Экран | Элементы интерфейса |
|---|---|
| **Тексты** (стартовый) | Список карточек текстов: заголовок, тема, число вопросов, отметка «пройден, X/Y». Кнопка «Читать». |
| **Чтение** | Две колонки: слева текст с подсвеченными словами, справа вопросы с радиокнопками A–D. Кнопки «← К текстам» и «Проверить» (активна, когда отвечены все вопросы). Попап у слова: слово, перевод (готовый или поле ввода), пример, кнопка «В словарь» или отметка «Уже в словаре». На узком экране колонки идут друг под другом. |
| **Результат** | «Правильно X из Y». Список вопросов: ответ пользователя, правильный ответ, ✓/✗. Кнопки «Пройти ещё раз», «К текстам», «В словарь». |
| **Словарь** | Таблица: слово, перевод, пример, из какого текста, статус (учу / выучено). Кнопки «Удалить» у каждой строки и «Повторить (N)» сверху. Если словарь пуст, показывается подсказка. |
| **Карточки** | Карточка со словом; клик переворачивает её и показывает перевод и пример. Кнопки «Знаю» и «Не знаю», прогресс «3 / 10», в конце сводка и «Вернуться в словарь». |

Варианты, которые рассматривались (выбраны отмеченные ✔):
- Экран чтения: ✔ две колонки / одна колонка / вкладки «Текст | Вопросы».
- Навигация: ✔ верхнее меню / главная-дашборд / нижние вкладки.

## 4. Функции v1
- 3 встроенных демо-текста в стиле IELTS Academic (≈300–400 слов, 4–5 вопросов multiple choice, 8–10 подсвеченных слов с переводом и примером в каждом). Тексты оригинальные, а не скопированные из реальных экзаменов.
- Выбор ответа, проверка, экран результата с разбором.
- Сохранение лучшего результата по каждому тексту.
- Добавление слова в словарь двумя способами (подсвеченное или любое), защита от дублей.
- Словарь: просмотр и удаление.
- Карточки: в сессию попадают слова со статусом «учу». «Знаю» переводит слово в «выучено», «Не знаю» оставляет его в очереди.

## 5. Не входит в v1
- Другие типы вопросов: True/False/Not Given, gap fill, matching headings.
- Таймер и режим экзамена на 60 минут, подсчёт band score.
- Загрузка собственных текстов, редактор вопросов.
- Автоперевод через внешние API, озвучка слов.
- Интервальное повторение (SM-2 и подобные), статистика и графики.
- Аккаунты, синхронизация, сервер.
- Тесты, продуманный дизайн, тёмная тема.

## 6. Где хранятся данные
- **Контент** (тексты, вопросы, правильные ответы, словарик подсвеченных слов) лежит в `src/data/passages.json` в составе сборки.
- **Данные пользователя** хранятся в `localStorage` браузера:
  - `ielts.vocab`: массив `{ id, word, translation, example, passageId, status: 'learning'|'known', addedAt }`;
  - `ielts.results`: `{ [passageId]: { best, total, lastAt } }`.
- Чтение и запись обёрнуты в try/catch. Если `localStorage` недоступен, приложение работает, но данные не сохраняются.

## 7. Технические решения
- React + Vite, JavaScript (без TypeScript), npm.
- Навигация через состояние `screen` в `App` без react-router: экранов всего 5, лишняя зависимость не нужна.
- Состояние словаря и результатов хранится в `App` (или в одном хуке `useLocalStorage`) и передаётся через props.
- Кликабельные слова: текст разбивается на токены, подсвеченные слова сверяются со словариком текста без учёта регистра.
- Стили: один обычный CSS-файл с минимальной разметкой, без UI-библиотек.
- Структура: `src/screens/*` (5 экранов), `src/components/WordPopup.jsx`, `src/data/passages.json`, `src/storage.js`.

## 8. Три проверки результата
1. **Чтение и проверка:** открыть текст 1, ответить на все вопросы, нажать «Проверить». Счёт «X из Y» совпадает с числом верных ответов, у неверных показан правильный вариант. После перезагрузки на экране «Тексты» видна отметка «пройден, X/Y».
2. **Слова в словарь:** в тексте кликнуть одно подсвеченное слово и добавить его, затем кликнуть обычное слово, ввести перевод и добавить. В меню «Словарь (2)», оба слова есть в таблице и остаются после перезагрузки страницы. Повторное добавление не создаёт дубль.
3. **Карточки:** запустить «Повторить» и для одного слова нажать «Знаю», для другого «Не знаю». В словаре первое слово получает статус «выучено», второе остаётся в «учу», в следующей сессии карточек показывается только второе.

## 9. Дополнительные функции (только по согласованию, в v1 не включены)
- True/False/Not Given как второй тип вопросов.
- Таймер на текст (20 минут) и пересчёт счёта в примерный band.
- Подсветка в тексте фрагмента, где находится ответ (после проверки).
- Режим «вставить свой текст» с ручным добавлением вопросов.
- Интервальное повторение (Leitner-коробки) вместо простого «Знаю/Не знаю».
- Экспорт словаря в CSV.
