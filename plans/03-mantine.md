# План 03: переход на библиотеку компонентов Mantine

**Статус:** объединён с [планом 04](04-design-apply.md) и выполнен в его рамках (2026-11-10).
**Дата:** 2026-11-10
**Основание:** пользователь выбрал Mantine из вариантов (Mantine, Gravity UI, shadcn/ui, Ant Design, MUI, Carbon) и согласовал этот план.

## Цель
Заменить самодельные элементы интерфейса готовыми компонентами Mantine.

Остаётся без изменений:
- функции, тексты интерфейса и сценарий;
- данные в `localStorage`: ключи `ielts.vocab` и `ielts.results` и их формат;
- общая компоновка экранов.

Новые функции не добавляются.

## Проверка доступности (2026-11-10)
- `@mantine/core` и `@mantine/hooks` — лицензия MIT, последняя версия 9.8.0 (вышла 2026-11-09).
- Нужен React `^19.2.0`, в проекте React и React DOM 19.3.1 — совместимо.
- `npm install --dry-run` прошёл без ошибок, проект при этом не изменился.

## Зависимости
- **Нужны** (точные версии):
  - `@mantine/core@9.7.4` и `@mantine/hooks@9.7.4`;
  - 9.7.4 вышла 2026-10-25, это проверенная версия вместо самой свежей.
- **Не нужны:**
  - `postcss-preset-mantine`, `postcss-simple-vars` — нужны только для миксинов Mantine в своём CSS, мы их не используем;
  - `@mantine/form`, `@mantine/notifications`;
  - библиотека иконок: используем символы ✓/✗ и свою SVG-корзину.

## Что заменяем

| Сейчас | Компонент Mantine | Где |
|---|---|---|
| Кнопки (основные синие и обычные) | `Button` (`filled` / `default`), `disabled` сохраняется | все экраны |
| Меню «Тексты / Словарь» | `Button`: `variant="light"` у активного пункта, `subtle` у остальных | шапка (`App.jsx`) |
| Поле «Ваш перевод» | `TextInput` (тот же placeholder и автофокус) | `WordPopup.jsx` |
| Варианты ответа A–D | `Radio.Group` + `Radio`; после проверки `disabled`, зелёная и красная подсветка | `Reading.jsx` |
| Отметки ✓/✗ у вопросов | `ThemeIcon` (зелёный / красный, круглый) | `Reading.jsx` |
| «Правильно X из Y» | `Badge` | `Reading.jsx` |
| Статус «● учу» / «✓ выучено» | `Badge` (оранжевый / зелёный, `light`) | `Vocabulary.jsx` |
| «✓ В словаре · учу/выучено» | `Badge` | `WordPopup.jsx` |
| Корзина | `ActionIcon` (`subtle`, красный при наведении) со своей SVG-иконкой | `Vocabulary.jsx` |
| Крестик × | `CloseButton` | `WordPopup.jsx` |
| Попап слова | `Popover` вокруг нажатого слова: сам выбирает место (снизу / сверху), закрывается по клику мимо и по Esc. Ручной расчёт позиции, подложка и закрытие при прокрутке больше не нужны | `Reading.jsx`, `WordPopup.jsx` |
| Карточки текстов и слов, пустые состояния, итог сессии | `Card withBorder` | все экраны |
| Полоска «знаю / не знаю» | `Progress.Root` + две `Progress.Section` | `Flashcards.jsx` |
| Точки в подписи полоски | `ColorSwatch` | `Flashcards.jsx` |
| Значок ✓ в итоге | `ThemeIcon` (`light`, круглый) | `Flashcards.jsx` |
| Заголовки, подсказки, «Отвечено X из Y», «1 / N» | `Title`, `Text c="dimmed"` | все экраны |

## Что остаётся своим
- Раскладка: две колонки на экране чтения, шапка, ширины и отступы страниц (свой CSS).
- Текст с кликабельными словами и жёлтой / зелёной подсветкой (аналога в Mantine нет).
- 3D-переворот карточки (CSS-анимация).
- Навигация через `screen` в `App.jsx`, `storage.js`, `passages.json`, все тексты интерфейса.

## Шаги
1. Установить `@mantine/core@9.7.4` и `@mantine/hooks@9.7.4`.
2. В `src/main.jsx` подключить `MantineProvider` и `@mantine/core/styles.css`. Тему собрать из токенов [DESIGN.md](../DESIGN.md): цвета, шрифты (Source Serif 4 для заголовков, Inter для остального), скругления, отступы и варианты компонентов. *(Изменено 2026-11-10 после согласования DESIGN.md; раньше было «близко к нынешнему виду».)*
3. Заменять по экранам, проверяя каждый:
   1. `PassageList.jsx`;
   2. `Reading.jsx` (кнопки, вопросы, отметки, счёт);
   3. `WordPopup.jsx`;
   4. `Vocabulary.jsx`;
   5. `Flashcards.jsx` (кнопки, пустые состояния, итог);
   6. шапка в `App.jsx`.
4. Убрать из `src/index.css` стили, которые теперь даёт Mantine. Раскладку, подсветку слов и переворот карточки оставить.
5. Проверить во встроенном браузере (1100 px и 375 px):
   - три проверки из раздела 8 PRD;
   - цвета разбора: верный ответ зелёный, ошибочный красный и зачёркнутый;
   - попап у нижнего края экрана и у сохранённого слова;
   - существующие данные пользователя в `localStorage` читаются без изменений;
   - нет горизонтальной прокрутки;
   - `npm run build` без ошибок, нет новых ошибок в консоли.
6. Обновить документы:
   - PRD: «Технические решения» (Mantine вместо «без UI-библиотек»), «Дизайн», журнал;
   - CLAUDE.md: снять запрет на библиотеки компонентов;
   - статус этого плана.

## Риски
- Внешний вид немного изменится: кнопки, радиокнопки и метки будут выглядеть как в Mantine, хотя тема подстраивается под нынешний вид. Глобальные стили Mantine могут слегка поменять отступы и шрифт.
- Для подсветки верного и ошибочного ответа в разборе понадобятся свои классы на `Radio`.
- Размер сборки вырастет. Для локального демо это не критично.

## Не входит
- Новые функции, изменение компоновки, тёмная тема, тесты, Motion и другие библиотеки.
