## Проверка
- Пустой словарь: на экране чтения видна полная подсказка. После добавления слова — короткая.
- Режим разбора: подсказка про разбор ошибок не изменилась.
- Карточки: под кнопками «Знаю / Не знаю» нет ссылки «Вернуться в словарь», переход через меню работает.
- Пустой список текстов: временно передать пустой массив и убедиться, что видно сообщение (код возвращается обратно).
- `npm run build` без ошибок, нет ошибок в консоли, нет горизонтальной прокрутки на 375 px.

## Результат проверки
Проверено во встроенном браузере (2026-11-10):
